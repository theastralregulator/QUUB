# QUUB - Development Rules

## General Principles
- **Aesthetics First:** Ensure a premium, dynamic, and visually stunning design. Use rich aesthetics, harmonious color palettes, modern typography, smooth gradients, and micro-animations.
- **Technology Stack:**
  - Core: HTML and vanilla JavaScript.
  - Styling: Vanilla CSS (no TailwindCSS unless explicitly requested).
  - Framework: Use frameworks like Next.js or Vite only if a complex web app is requested and explicitly approved.
- **Responsive Design:** Ensure all pages are fully responsive across desktop, tablet, and mobile devices.

## Coding Standards
- **Structure:** Write clean, modular, and well-documented code.
- **Styling:** Use a design system with predefined CSS tokens and utilities in `index.css`. Do not use ad-hoc utility classes.
- **SEO Best Practices:** Implement proper title tags, meta descriptions, heading structures, semantic HTML, and unique IDs on every page.
- **No Placeholders:** Generate and use functional demonstrations or actual images instead of placeholders.

## Workflow
1. **Plan and Understand:** Fully outline features and design inspiration before coding.
2. **Build the Foundation:** Establish the core design system.
3. **Create Components:** Build focused, reusable UI components.
4. **Assemble Pages:** Incorporate components into full layouts with proper navigation.
5. **Polish and Optimize:** Review UX, ensure smooth interactions, and optimize performance.
