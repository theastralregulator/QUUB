# QUUB - Project Requirements

## Overview
QUUB is a freelance job website designed to connect workers/artists with customers looking to hire for various projects.

## Core Features

1. **User System**
   - Anyone can register an account.
   - Users choose their identity during registration: "I am a worker/artist" or "I am a customer".
   - Different interfaces show up after login depending on the chosen identity.

2. **Worker/Artist Side**
   - Can edit profile (avatar, skills description, portfolio images).
   - Can browse all job opportunities.
   - Can click "Interested" and send messages to customers.
   - Track job applications.

3. **Customer Side**
   - Can post jobs (title, description, budget, deadline).
   - Can view all jobs they posted.
   - Can receive and reply to messages from workers.
   - Can mark jobs as completed.

4. **Messaging System**
   - Workers and customers can message each other privately.
   - Show message timestamps.
   - Has read/unread status.

5. **Other Requirements**
   - Clean, modern interface that works on phones (responsive).
   - Customers always free forever.
   - No payment system needed yet (can add later).
